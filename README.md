# Hnin Shwe Sin Moe — Portfolio

A responsive personal portfolio website built from the information in Hnin Shwe Sin Moe's CV.

## Files
- `index.html` — portfolio structure and content
- `style.css` — responsive styling
- `script.js` — mobile navigation and current year

## How to run
1. Keep all three files in the same folder.
2. Double-click `index.html` to open it in a browser.
3. To publish online, upload the folder to a static hosting service.

## Personalization
The profile card currently uses an HSSM placeholder instead of a photo. Replace the `HSSM` text inside `.profile-placeholder` with an image if desired.
